06 / GOOD TO KNOW

A few
little things.

Can I book a real appointment here?+

No. Maison Muse is a fictional web design portfolio project. The booking feature demonstrates how an appointment journey could look, but it does not send or store appointments.

Are the treatment prices real?+

No. All treatment names, durations and prices are examples created to demonstrate a salon website. A real client would supply their own service list.

Can a business have a website like this?+

Yes. Wickens Web Co can tailor this type of visual design for a real business, with its own brand identity, photographs, service information and functional integrations.

Is this a WordPress website?+

No. This concept uses HTML, CSS and JavaScript and is suitable for GitHub Pages. WordPress builds would require a separate WordPress project and hosting environment.
