06 / Good to know

A few
little things.

Can I book a real appointment here?+

No. Maison Muse is a fictional portfolio concept. The booking interaction previews a user journey; it does not create an appointment or send any data.

Are the treatments and prices real?+

No. Services, durations and prices are examples. A real salon would provide its own verified service information.

Could my business have a website like this?+

Yes. Wickens Web Co creates tailored websites for real businesses, with their own branding, images, copy and approved integrations.

Is this website built with WordPress?+

No. This portfolio demo is hand-coded with HTML, CSS and JavaScript and designed for GitHub Pages. A WordPress implementation is a separate development process.
